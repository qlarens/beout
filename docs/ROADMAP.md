## Фаза 1. Надёжная запись трека (фундамент)

Как работает Live-геопозиция в Bot API:
- Первая точка приходит как `message` с полем `location` (там есть `live_period`).
- Каждое следующее обновление приходит как **`edited_message`** с `location`. Время точки — `edit_date`.
- Полезные поля: `latitude`, `longitude`, `horizontal_accuracy`, `heading`, `live_period`.
- Интервал между точками неровный (примерно от 4 до 15 секунд, иногда больше). Убедись, что бот подписан на `edited_message` (в `allowed_updates`).

Что сделать:
1. **Модель тренировки**: таблицы/сущности `users`, `activities` (тип, статус, начало/конец, итоги), `track_points` (lat, lon, accuracy, timestamp, флаг «отброшена»). Каждая точка привязывается к активной тренировке пользователя.
2. **Фильтрация точек**:
   - отбрасывать точки с `horizontal_accuracy` больше порога (по умолчанию 30 м, в конфиг);
   - отбрасывать «скачки»: если скорость между соседними точками нереальна для типа активности (вело больше 70 км/ч, бег больше 25 км/ч, ходьба больше 10 км/ч);
   - игнорировать дрожание на месте: сдвиг меньше 3 м не добавляет дистанцию.
3. **Расчёт дистанции** — формула гаверсинуса по отфильтрованным точкам.
4. **Автопауза**: если скорость ниже порога (вело меньше 3 км/ч, бег меньше 3 км/ч, ходьба меньше 1 км/ч) дольше 10–15 секунд, время не идёт в «время в движении». Храни отдельно общее время и время в движении.
5. **Завершение тренировки** — три способа:
   - кнопка «Финиш» в Mini App и inline-кнопка в боте;
   - автоматически, если точек нет N минут (по умолчанию 15, в конфиг);
   - когда истёк `live_period` или пользователь остановил трансляцию.
6. **(Опционально, за флагом)** привязка трека к дорогам через OSRM `/match`, чтобы трек на поворотах не «срезался». Если сервис недоступен — работать без него.
7. **Онбординг**: при первом запуске Mini App показать короткую инструкцию с картинкой: «📎 → Геопозиция → Транслировать геопозицию → выбери время → Старт». В боте — то же текстом с кнопкой.

Готово, когда: трек с шумными точками (тестовые данные со скачками и стоянками) даёт правдоподобную дистанцию и время в движении, тренировка корректно завершается всеми тремя способами.

## Фаза 2. Типы активности: велосипед, бег, ходьба

1. Выбор типа при старте (по умолчанию — последний использованный) + настройка «тип по умолчанию».
2. Метрики по типу:
   - **Велосипед**: скорость (средняя/максимальная) в км/ч.
   - **Бег/ходьба**: **темп** в мин/км (формат `5:30 /км`), средний и лучший.
   - **Сплиты по каждому километру** для бега и ходьбы (время каждого км).
3. **Калории** по MET: `ккал = MET × вес(кг) × часы в движении`. MET зависит от типа и скорости (таблицы по Compendium of Physical Activities вынеси в конфиг). Вес — в настройках профиля, по умолчанию 70 кг. Показывать как «≈ N ккал».
4. Максимальная скорость/лучший темп считаются по сглаженным данным (скользящее среднее по нескольким точкам), чтобы один шумный отрезок не давал рекорд.

Готово, когда: один и тот же трек корректно показывается как вело (км/ч) и как бег (темп, сплиты), калории считаются по типу.

## Фаза 3. Экран итогов и карточка для чата (приоритет №1 для роста)

1. **Экран итогов** после финиша: карта маршрута, дистанция, время в движении, скорость/темп, калории, (позже) набор высоты, сплиты.
2. **Карточка тренировки — картинка** для отправки в чаты:
   - генерируется на сервере (например, satori + resvg, node-canvas или Pillow — по стеку проекта);
   - стиль бренда: тёмный фон `#0E1116`, линия маршрута салатовым `#C6F432`, точка старта белая, точка финиша салатовая, шрифт Inter / Inter Display;
   - маршрут рисуется как нормализованная полилиния, без тайлов карты (так проще и красивее);
   - на карточке: тип активности, дистанция, время, скорость или темп, логотип и `APP_NAME`.
3. **Поделиться**: кнопка в Mini App и в боте. Через `sendPhoto` с подписью и inline-кнопкой «Открыть трекер» (ссылка вида `t.me/<bot>/<app>?startapp=...`). Если стек позволяет — используй `savePreparedInlineMessage` + `shareMessage` из Mini App, чтобы делиться в любой чат.

Готово, когда: после тренировки одной кнопкой можно отправить красивую карточку в любой чат, и из неё можно открыть приложение.

## Фаза 4. История, статистика, рекорды

1. Список тренировок с фильтром по типу, просмотр любой тренировки (экран итогов).
2. Итоги за неделю и месяц: дистанция, время, количество тренировок — отдельно по типам.
3. **Серии**: сколько дней/недель подряд пользователь тренировался.
4. **Личные рекорды**: самая длинная тренировка, лучший темп на 1 км / 5 км (бег), максимальная скорость (вело). При новом рекорде — отметка на экране итогов и на карточке.
5. Удаление тренировки.

## Фаза 5. Социальное: совместные тренировки и рейтинги в группах

1. **Совместная тренировка**:
   - пользователь создаёт «сессию» и получает ссылку-приглашение (`startapp=session_<id>`);
   - друг открывает ссылку, оба транслируют Live-геопозицию боту, бот привязывает обе тренировки к сессии;
   - в Mini App — одна карта с позициями обоих участников (обновление через polling или WebSocket), общая статистика сессии.
2. **Рейтинг в группе**:
   - бота можно добавить в групповой чат (например, чат бегового клуба);
   - команда `/top` и еженедельный автопост: рейтинг участников группы по дистанции за неделю (отдельно бег/вело);
   - в рейтинге участвуют только те, кто сам запустил бота и согласился (кнопка «Участвовать в рейтинге этой группы»).
3. Приватность: по умолчанию тренировки видны только владельцу; делиться — только явным действием.

## Фаза 6. Безопасность и высота

1. **SOS**: кнопка в Mini App во время тренировки отправляет выбранным контактам сообщение с последней геопозицией. Важно: бот может писать только тем, кто уже запускал бота, поэтому контакт добавляется через ссылку-приглашение, по которой он сам открывает бота. Обязательное подтверждение перед отправкой, чтобы не нажать случайно.
2. **Набор высоты**: в локации Telegram высоты нет. Запрашивай высоту по координатам через внешний сервис (например, Open-Meteo Elevation API, запросы пачками), сглаживай и считай набор только при перепаде больше 2–3 м. Если сервис недоступен — просто не показывать высоту.

## Интерфейс Mini App (применять во всех фазах)

- **Тема**: учитывать `Telegram.WebApp.themeParams` (светлая/тёмная тема Telegram), но с фирменными акцентами: фон `#0E1116` (в тёмной теме), акцент `#C6F432`, белый для основных цифр, приглушённый серый `#B7BDC7` для подписей.
- **Шрифт**: Inter (текст) и Inter Display (крупные цифры и заголовки).
- **Экран активной тренировки**: огромные цифры (время, дистанция, скорость/темп), читаемые на ходу; крупная кнопка «Пауза/Финиш» внизу, удобная для одной руки; кнопки не меньше 44 px.
- **Тактильный отклик**: `Telegram.WebApp.HapticFeedback` на старт, паузу, финиш и новый рекорд.
- Использовать `MainButton`/`BackButton` Telegram там, где это естественно.
- Экраны: **Главная** (кнопка старта, последняя тренировка, итоги недели) → **Активная тренировка** → **Итоги** → **История** → **Профиль/настройки** (вес, тип по умолчанию, участие в рейтингах) → **Группа/рейтинг**.
- Никаких эмодзи в качестве иконок интерфейса — используй один набор линейных SVG-иконок.
